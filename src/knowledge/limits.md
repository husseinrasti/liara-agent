# محدودیت‌های API لیارا (limits)

این موارد از طریق API عمومی لیارا در دسترس نیست و دستیار باید صادقانه همین را به کاربر بگوید.

## لاگ دسترسی HTTP (access logs) وجود ندارد

- API فقط خروجی خود برنامه (stdout/stderr کانتینر) را می‌دهد؛ آمار کد وضعیت (۲۰۰/۵۰۰) یا لاگ درخواست‌ها جداگانه وجود ندارد.
- جایگزین: بررسی سلامت HTTP خودمان (http_health_check) و خطاهایی که برنامه در لاگ چاپ می‌کند. پلتفرم‌هایی که با وب‌سرور اجرا می‌شوند (مثل PHP) ممکن است خودشان خطوط درخواست را در لاگ بنویسند.

## انتشار با git push وجود ندارد

- API فقط «آپلود فایل فشرده‌ی کد» و «ساخت release» را دارد. دستیار خودش کد را بسته‌بندی و آپلود می‌کند؛ اتصال GitHub فقط از پنل لیارا ممکن است.

## کنترل DNS ایرنیک (IRNIC) یا ثبت‌کننده‌ی دامنه ممکن نیست

- دستیار نمی‌تواند داخل پنل ایرنیک یا شرکت فروشنده‌ی دامنه تغییری بدهد؛ فقط رکورد لازم را دقیق می‌گوید و با `check_domain` بررسی می‌کند که درست انجام شده است.

## اعلان (webhook) و هشدار خودکار وجود ندارد

- لیارا رویدادها را به ما خبر نمی‌دهد؛ پایشگر (watcher) دستیار هر چند ثانیه وضعیت را می‌پرسد.

## برگشت به نسخه‌ی قبلی (rollback)

- endpoint مستقیمی برای «انتشار دوباره‌ی نسخه‌ی X» در مستندات نیست. دستیار کد هر انتشار را نگه می‌دارد و برای برگشت، همان کد را دوباره منتشر می‌کند. نسخه‌هایی که خارج از دستیار منتشر شده‌اند قابل برگرداندن خودکار نیستند.

## شارژ حساب

- افزایش موجودی فقط از پنل لیارا و توسط خود کاربر ممکن است. دستیار فقط موجودی را می‌خواند و کم بودنش را هشدار می‌دهد.

## نگهداری لاگ‌ها محدود است

- مدت نگهداری لاگ به «بسته‌ی امکانات» (free/standard/pro) بستگی دارد؛ لاگ‌های قدیمی‌تر از آن قابل خواندن نیستند.

## دسترسی شِل (shell)

- اجرای فرمان داخل کانتینر از طریق WebSocket ممکن است، اما این دستیار فقط فرمان‌های فقط‌خواندنی (مثل `ls`، `df -h`، `free -m`) را و آن هم با تأیید صریح اجرا می‌کند.
