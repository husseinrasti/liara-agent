# متغیرهای محیطی (environment variables)

متغیر محیطی مقداری است که بیرون از کد به برنامه داده می‌شود؛ مثل آدرس پایگاه داده، کلید API یا حالت اجرا.

## تنظیم در لیارا

- با ابزار update_envs (یا پنل لیارا) تنظیم می‌شوند. API لیارا هر بار **کل** فهرست متغیرها را جایگزین می‌کند؛ این دستیار بقیه‌ی متغیرها را حفظ می‌کند و فقط موارد خواسته‌شده را اضافه، عوض یا حذف می‌کند.
- بعد از هر تغییر، سرویس یک بار ری‌استارت می‌شود تا مقدارهای جدید اعمال شوند.
- فایل `.env` پروژه آپلود نمی‌شود؛ مقدارهایش باید به‌صورت متغیر محیطی تنظیم شوند.
- مقدار متغیرهای محرمانه (رمز، توکن، کلید) را دستیار هرگز حدس نمی‌زند و در گزارش‌ها نشان نمی‌دهد؛ مقدار را خود کاربر می‌دهد.

## نکته‌ها

- `PORT` را لازم نیست تنظیم کنید؛ پورت هنگام انتشار مشخص می‌شود و برنامه باید روی همان پورت گوش بدهد.
- `NODE_ENV=production` برای برنامه‌های Node معمولاً مناسب است.
- در پروژه‌های فرانت‌اند (react، vue، angular) متغیرها هنگام ساخت (build) داخل کد قرار می‌گیرند؛ بعد از تغییرشان باید دوباره منتشر کرد.
- در Laravel، `APP_KEY` و تنظیمات `DB_*` لازم‌اند.

## خطاهای رایج

- `Error: X is not set` یا `KeyError: 'X'`: متغیر X تنظیم نشده است.
- `ECONNREFUSED 127.0.0.1` یا `localhost`: معمولاً آدرس پایگاه داده (مثل DATABASE_URL) تنظیم نشده و برنامه به سرور محلی وصل می‌شود.

منابع: POST /v1/projects/update-envs، liara-cli (`env set`, `env unset`)
