# دامنه‌های ‎.ir و ایرنیک (IRNIC)

دامنه‌های `.ir` در ایرنیک (irnic.ir) ثبت می‌شوند. ایرنیک خودش رکورد CNAME نمی‌سازد؛ فقط «سرورهای نام» (nameserver یا NS) دامنه را نگه می‌دارد. پس رکوردها باید در یک سرویس DNS ساخته شوند.

## روش ۱: استفاده از DNS لیارا (پیشنهادی برای دامنه‌ی اصلی)

1. در پنل لیارا بخش DNS، دامنه را اضافه کنید؛ لیارا نام دو سرور نام (NS) را نشان می‌دهد.
2. وارد irnic.ir شوید → بخش «دامنه‌های من» → دامنه را انتخاب کنید → «تغییر سرورهای نام».
3. سرورهای نامی را که پنل DNS لیارا نشان داده وارد و ذخیره کنید.
4. در پنل DNS لیارا رکورد لازم برای برنامه را بسازید (برای `www` رکورد CNAME به مقصدی که لیارا داده است).
5. صبر کنید: تغییر NS در ایرنیک ممکن است چند ساعت (تا ۲۴ ساعت) طول بکشد.

## روش ۲: DNS فعلی خودتان را نگه دارید

اگر دامنه از قبل به یک سرویس DNS دیگر (مثلاً شرکت میزبانی) وصل است:

1. در پنل همان سرویس، رکورد `CNAME` برای `www` بسازید که به مقصد CNAME لیارا اشاره کند.
2. برای دامنه‌ی اصلی بدون www، اگر CNAME مجاز نیست از `ALIAS`/`ANAME` استفاده کنید یا روش ۱ را انتخاب کنید.
3. TTL را کم (مثلاً ۳۰۰ ثانیه) بگذارید تا تغییرات زودتر اعمال شود.

## چیزی که دستیار نمی‌تواند انجام دهد

دستیار به حساب ایرنیک یا پنل DNS شما دسترسی ندارد و نمی‌تواند در آن تغییری بدهد. فقط رکورد لازم را دقیق می‌گوید و بعد از تنظیم، با بررسی دامنه (check_domain) مطمئن می‌شود درست انجام شده است.

منابع: https://irnic.ir، https://developers.liara.ir (Domains/DNS API)
